# Deployment Information

## Public URL

After pushing the latest `render.yaml`, Render will deploy the productionized project as:

```text
https://day12-legal-rag-agent.onrender.com
```

Previous quickstart URL used during testing:

```text
https://day12-quickstart-agent.onrender.com
```

## Platform

Render

## Project

The submitted project in `06-lab-complete` is now a productionized version of the Day07 agent:

```text
Vietnamese Legal RAG Agent
```

It uses Day07 legal-document RAG logic and includes:

- 5 Vietnamese legal documents from the Day07 project
- Offline retrieval over chunked legal documents
- API key authentication
- Rate limiting
- Cost guard
- Health and readiness endpoints
- Docker multi-stage build
- Redis-backed production stack

## Render Configuration

Config file:

```text
render.yaml
```

Important settings:

```yaml
name: day12-legal-rag-agent
runtime: docker
rootDir: 06-lab-complete
healthCheckPath: /health
```

## Test Commands

### Health Check

```bash
curl.exe https://day12-legal-rag-agent.onrender.com/health
```

Expected result:

```json
{"status":"ok"}
```

### API Test With Authentication

Replace `<RENDER_AGENT_API_KEY>` with the `AGENT_API_KEY` value from Render Dashboard.

```powershell
$body = @{ question = "Luat phong chay chua chay quy dinh gi ve trach nhiem phong chay?" } | ConvertTo-Json

Invoke-RestMethod -Method POST https://day12-legal-rag-agent.onrender.com/ask `
  -Headers @{ "X-API-Key" = "<RENDER_AGENT_API_KEY>" } `
  -ContentType "application/json; charset=utf-8" `
  -Body $body
```

## Environment Variables

Render:

- `ENVIRONMENT=production`
- `APP_NAME=Vietnamese Legal RAG Agent`
- `APP_VERSION=1.0.0`
- `AGENT_API_KEY` generated by Render
- `JWT_SECRET` generated by Render
- `DAILY_BUDGET_USD=5.0`
- `RATE_LIMIT_PER_MINUTE=20`
- `LEGAL_RAG_DATA_DIR=/app/data`
- `PORT` provided by Render at runtime

Local:

- `AGENT_API_KEY=local-final-secret`
- `JWT_SECRET=local-final-jwt-secret`
- `REDIS_URL=redis://redis:6379/0`
- `LEGAL_RAG_DATA_DIR=/app/data`
